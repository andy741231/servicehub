# Church Directory Manuals

HTML sources for the two user guides: `serving-ones-guide.html` and `saints-guide.html` (shared styling in `manual.css`).
To rebuild the PDFs, run `node docs/manuals/build.mjs` (requires Microsoft Edge or Chrome installed).
Output PDFs are written to `docs/manuals/pdf/`; review previews live in `docs/manuals/preview/`.
