Form Builder — Layout Mockups

Seven mockups exploring the builder editor: the current layout for reference, plus six modern-minimal redesign directions. Each is a standalone HTML file — click through to explore the interactions. Same form content, same design tokens, different layout philosophy.

Current 3-pane layout

Left field palette (always visible, 5 categories) + center canvas (section cards with field cards) + right properties panel (3 tabs, accordion sections). Functional but dense — this is the "before" state the redesigns improve on.

Batch 1 — Redesign directions A–C

A

Linear ultra-minimal

Slim icon rail that expands on hover. Contextual right panel — only appears when a field is selected. Keyboard-first with ⌘K command palette.

Slim rail Contextual panel ⌘K palette
B

Notion document canvas

No sidebars — the form IS the document. Inline field blocks, "/" slash command to add fields, properties as a floating popover on click.

No sidebars Slash command Popover props
C

Fillout card-preview

Center stage renders the form as the user will see it — real inputs, real submit button. Left palette chips + right properties panel. Device toggle changes the stage.

Live stage Palette chips Device toggle

Batch 2 — Redesign directions D–F

D

Split-view dual canvas

Figma-style: builder outline on the left, live form preview on the right — both always visible. No sidebars; properties as a floating popover. Draggable vertical divider.

Split panes Live preview Draggable divider
E

Outline + inspector

VS Code-style: collapsible structure tree on the left, canvas in the center, persistent inspector on the right. Status bar with field count. Best for long, complex forms.

Outline tree Persistent inspector Status bar
F

Focused single-field

Typeform-style: one field at a time, large and centered. Vertical filmstrip navigator on the left. Progress indicator. Calmest direction — great for conversational forms.

One field at a time Filmstrip nav Progress bar
